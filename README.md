# AstroMate 🌌

AstroMate یک دستیار شخصی هوشمند برای خودشناسی و رشد فردی‌ست —  
بر پایه‌ی چارت تولد، تحلیل آسترولوژیک و روان‌شناسی انسانی.

## 🎯 هدف MVP

در نسخه اولیه، کاربر با وارد کردن اطلاعات تولدش (تاریخ، ساعت، مکان)،  
یک گزارش PDF شخصی دریافت می‌کند شامل:

- معرفی شخصیت کلی
- ویژگی‌های روان‌شناختی
- توانایی‌ها و پتانسیل‌ها
- مسیرهای شغلی و عاطفی مناسب
